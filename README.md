# IFM — Infinite Macro

**IFM (Infinite Macro)** is a simple open-source, lightweight and easy-to-use mouse macro for automating clicks.

Built with ❤️ by [nxthxndev](https://github.com/nxthxndev).

---

## ✨ Features

* 🖱️ **Mouse auto-clicking**
* 🔘 Support for **Left, Middle and Right** mouse buttons
* ⚡ **Clicks per second** mode
* ⏱️ **Interval (ms)** mode
* 🔢 Custom number of clicks
* ♾️ **Infinite clicking** with `0` clicks
* ⌨️ Customizable hotkey
* 🌐 **Global Start/Stop hotkey**
* 🪶 Simple and lightweight interface
* 🚀 Designed to be fast and easy to use

---

## 🚀 Usage

Using IFM is simple:

1. **Choose a speed mode**

   * `Interval (ms)`
   * `Clicks/sec`
2. **Set your speed or interval**
3. **Select the mouse button**

   * Left
   * Middle
   * Right
4. **Choose the click mode**
5. **Set the number of clicks**
6. Press **`F6`** to start or stop the macro

> The global hotkey works even when IFM is not the currently focused window.

---

## ⚡ Speed Modes

### Interval

The **Interval** mode lets you control the delay between each click in milliseconds.

For example:

```text
Interval: 100 ms
```

This means IFM will perform one click every **100 milliseconds**.

Lower values = faster clicking.

---

### Clicks/sec

The **Clicks/sec** mode lets you specify how many clicks should be performed every second.

For example:

```text
Clicks/sec: 10
```

IFM will attempt to perform **10 clicks per second**.

---

## ♾️ Infinite Mode

Want the macro to keep clicking until you stop it?

Simply set the number of clicks to:

```text
0
```

When `0` clicks are selected, IFM will run indefinitely.

Press **`F6`** again to stop the macro.

---

## ⌨️ Hotkey

The default **Start/Stop** hotkey is:

```text
F6
```

The hotkey is global, meaning you can start or stop the macro even when IFM is not focused.

The hotkey can also be customized from the application.
