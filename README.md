# IFM - Infinite Macro

A simple and lightweight mouse macro made by [nxthxndev](https://github.com/nxthxndev).

## Features

- Mouse auto-clicking
- Left, Middle and Right mouse buttons
- `Interval (ms)` mode
- `Clicks/sec` mode
- Custom number of clicks
- Infinite clicking with `0` clicks
- Customizable hotkey
- Global Start/Stop hotkey
- Simple and lightweight interface

## Usage

1. Choose your speed mode.
2. Set the speed or interval.
3. Select a mouse button.
4. Choose the click mode.
5. Set the number of clicks.
6. Press `F6` to start or stop the macro.

### Infinite Mode

Set the number of clicks to `0` to run the macro indefinitely.
